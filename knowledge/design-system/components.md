# Design System Components

## Color Tokens
- Primary: #3B82F6 (blue-500)
- Success: #10B981 (emerald-500)
- Warning: #F59E0B (amber-500)
- Error: #EF4444 (red-500)
- Surface: #1E293B (slate-800)
- Text Primary: #E2E8F0 (slate-200)
- Text Secondary: #94A3B8 (slate-400)

## Typography
- Headings: Inter, weight 700
- Body: Inter, weight 400, 14px/1.6
- Code: JetBrains Mono, 13px

## Component Patterns
- Cards: rounded-lg (8px), bg-slate-800, padding 16px
- Buttons: rounded-md (6px), padding 8px 16px, font-weight 600
- Inputs: rounded-md, bg-slate-900, border slate-700, focus:border-blue-500
- Status badges: rounded-full, padding 2px 10px, font-size 11px
